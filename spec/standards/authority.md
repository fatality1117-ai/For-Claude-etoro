- 我**不得**以任何理由建議刪除或跳過任何排定的貼文。
  「來源不足」是我的執行問題，去把來源補起來。
- **持倉比重不是一整篇發不發的判斷依據。** 持倉權重只用在第二部分的同分決勝。
- 我**不得**擅自更動貼文主題、順序、或行事曆結構。要調整，寫進回報請 Ed 決定，
  在 Ed 回覆之前照原訂執行。
- **不要憑持倉反推 thesis。** thesis 的正本在 `standards/thesis.md`，
  來源是 Ed 自己寫的 eToro profile。要判斷關聯性就去讀它。

# 第二部分：選材規則（決定「一篇之內寫什麼、給多少篇幅」）

適用範圍：**已排定的貼文內部，題材的取捨與篇幅分配**。
不適用於：一篇貼文本身該不該存在（見第一部分）。

## 兩條線，目的不同，不互相排擠

**拉新線（Q2：熱門題材）**
目的 = 讓不認識 Ed 的人相信他對未來的判斷。
熱門本身沒有價值。「早就提出這個論點、而且後來被驗證」才是價值來源。

**留存線（Q3：深度題材）**
目的 = 讓現有 follower 與 copier 安心繼續追隨、繼續複製。
價值 = 看得出有在做功課、對持倉解釋得夠深。

## MECE 四象限

軸一 = 讀者與 Copier 的興趣（基準是**會複製 AI Alpha 的人**，不是全 eToro 大眾）
軸二 = 與 Thesis 的關聯性 —— **判準見 `standards/thesis.md`，不是我自己歸納的分類**

|            | Thesis 高 | Thesis 低 |
|---|---|---|
| **興趣高** | Q1 最優先，主篇幅 | Q2 拉新線 |
| **興趣低** | Q3 留存線 | Q4 不提 |

Q1 恆為最優先，Q4 恆為不提。Q2 / Q3 用下面的公式逐案判定。

## 評分公式

```
分數 = 興趣 + 關聯 + 稀缺 + 量級 + 早期紀錄
```

**興趣 0-3** — 3 大多數會主動點開｜2 知道的人有興趣｜1 要被說服才讀｜0 沒人在意

**關聯 0-3** — 問題是「**它在不在 AI 生態系的某一層**」，不是「它屬於我哪個桶子」。
  層次表在 `standards/thesis.md`。
  3 直接坐落在某一層或是該層的結構性變化｜2 影響某層的上下游但本身不在表上｜
  1 沾邊｜0 完全在生態系外

**稀缺 0 或 2** — 2 = eToro 動態牆與主流英文財經媒體看不到（日文中文一手來源、
  法說會細節、產業數據）；0 = 到處都有

**量級 0 或 1** — 1 = 單日 ±15% 以上、>$100 億併購、指標性公司 IPO/S-1、政策級事件

**早期紀錄 0 或 2** — 2 = 有**公開時間戳可佐證**的早期部位或早期貼文，
  且該論點已被驗證。查 `state/thesis-ledger.json`。查不到就是 0，不准腦補。

稀缺是留存線的引擎，早期紀錄是拉新線的引擎。兩條線都能上主篇幅，不會互相擠掉。

### 判定
- **≥6** → 主篇幅
- **4-5** → 寫，短段落
- **≤3** → 不寫

### 硬性排除（不論分數多高）
- **加密貨幣** —— Ed 的 Principles 明文 no crypto exposure。不寫、不評論。
- **技術分析語言** —— 線型、支撐壓力、均線、動能，一律不用。
- **投機性故事股** —— tangible innovation over speculation。

### 同分決勝
有持倉的排前面。持倉 0% 照樣可以寫，只是排後面、篇幅少。

# 第三部分：thesis 收據帳本

檔案：`state/thesis-ledger.json`

用途是**內部的**，三項：

1. **thesis 到持倉的對照** —— 支撐關聯性評分。
2. **主張紀錄** —— 哪天講過什麼、之後世界怎麼發展。用途是不同月份的貼文
   不自相矛盾、不重複講同一件事。記的是論點與後續事實，不是報酬率。
3. **我自己的校準** —— 哪些論點成立、哪些沒有。純內部，不出現在貼文。

**不是拿來跟讀者做績效檢討的。** Ed 明確表示不會用「我的持倉漲很多所以我是對的」
去說服人。報酬率可以寫，點到為止，並標明 snapshot 日期。

資料來源都是 eToro 原生、有平台時間戳、可被讀者驗證的：
- 持倉的 `openTime` / `openRate`（`get-my-positions-and-orders`）
- 過去貼文的時間戳（`GET /api/v1/feeds/users/13809545`）

**有收據才寫日期與價格，沒有就打 0 分，絕對不准用推測或記憶充數。**
